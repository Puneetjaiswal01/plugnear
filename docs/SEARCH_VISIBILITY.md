## Owner steps in Search Console

1. Open https://search.google.com/search-console/ using the business owner's Google account. Add a Domain property for `plugnear.in`, or select an existing verified property.
2. Copy Google's exact TXT verification value. At Hostinger add a **TXT** record: name `@`, content `google-site-verification=THE_EXACT_GOOGLE_VALUE`, TTL `14400` (or provider default). Preserve all existing A, CNAME, TXT and mail records. This is separate from the completed `app` CNAME. The placeholder must never be saved as a real record.
3. Return to Google and click Verify. Then open Sitemaps and submit `https://www.plugnear.in/sitemap.xml`.
4. Inspect `https://www.plugnear.in/` and `https://www.plugnear.in/ev-charger-near-me/`. Run Test live URL and Request indexing when eligible. Review Google's reason if indexing is refused; repeated requests do not speed up processing.
5. Monitor Sitemaps, Page indexing and Performance for actual crawl/index status and queries. Do not promise a fixed indexing date or search position.

## Search and AI limits

Google chooses when to crawl/index, where to rank pages and which sources AI Overviews cite. Ordinary search eligibility applies to AI Overviews; there is no special AI schema or extra file required. A page must be indexed and eligible for a snippet. Do not use the Indexing API for ordinary website pages or the deprecated sitemap ping endpoint. Add individual charger pages only when genuine approved inventory exists, with host permission and accurate public details. Do not create fake city pages, fake charging locations, ratings or reviews.
